.. _introduction:

Introduction
============

.. admonition:: Prerequisites

  The reader is assumed to be familiar with Neper's use.

Neper’s developer documentation aims to help newcomers understand and contribute to the project. It provides guidance for navigating the codebase and for implementing new features in a way that remains consistent with Neper’s design principles and coding practices.
This includes a description of the overall :ref:`structure`, the :ref:`workflow` and the :ref:`devenv` we use.  The document also gathers the descriptions of :ref:`science` that are not available elsewhere.

.. important :: If you find that something is missing or erroneous in this documentation, please let us know.
