# GSL

This directory contains the subset of the
[GNU Scientific Library](https://www.gnu.org/software/gsl/) (GSL), version
2.7.1, that is used by Neper.  The files are unmodified copies of the GSL
sources, with the same directory layout, except for:

- `config.h`, which replaces the one generated by GSL's `configure` script;
- `CMakeLists.txt` and this file, which are specific to Neper.

(see `COPYING`).

## Updating

The bundled files are the closure (in terms of symbols, for the `.c` files,
and of `#include`s, for all files) of the GSL functions called by Neper.  When
Neper starts using a new GSL function, copy the corresponding source file(s)
and their dependencies from the GSL source tree, and add the `.c` files to
`GSL_SOURCES` in `CMakeLists.txt`.  Missing files are reported at link time
(undefined `gsl_*` or `cblas_*` symbols) or compile time (missing headers).
